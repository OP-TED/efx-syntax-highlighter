EFX syntax highlighter demo

This page demonstrates the EFX syntax highlighter, an npm package that adds syntax highlighting and autocompletion for the EFX language to CodeMirror 6 editors. The package is published on npm, and its source code and instructions for use are on GitHub.

Select one of the sample texts below to display it in the editor. You may also edit the text. For EFX-2 text, the editor suggests what may follow at the cursor position: keywords, functions, and the identifiers of fields and nodes. The suggestions are displayed while you type. Press Ctrl+Space to display them at any other position, including inside template text. In this demonstration, the identifiers suggested are those found in the sample text; an application provides its own list.

In the list of suggestions, use the Up and Down arrow keys to move, Enter to insert the selected suggestion and Escape to close the list. This demonstration adds nothing to CodeMirror beyond the highlighter, so the editor has no undo function and no other keyboard shortcuts.
